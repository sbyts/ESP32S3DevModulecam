
Крок 1: Налаштування безкоштовного шлюзу в n8n

1. Зайдіть на сайт n8n.io або створіть безкоштовний акаунт на будь-якому аналогу (наприклад, Activepieces). Можна увійти через звичайний Google-акаунт (@gmail.com), корпоративна пошта не потрібна.
2. Створіть новий сценарій (Create first workflow).
3. Натисніть Add first step (Додати перший крок) та оберіть модуль Webhook.
4. У налаштуваннях Webhook змініть параметр HTTP Method на POST.
5. У полі Response Mode оберіть When Last Node Finishes (або просто залиште стандартний відгук 200 OK).
6. Зверху у вкладці Production URL скопіюйте посилання шлюзу. Воно виглядатиме приблизно так: https://n8n.cloud...
7. Натисніть на значок + після Webhook, щоб додати наступну дію.
8. Знайдіть у списку Google Drive та оберіть дію Upload a File.
9. Натисніть кнопку підключення акаунта і авторизуйте свій особистий Google Диск.
10. У полі File Content вкажіть назву бінарного об'єкта, який прийшов від Webhook (зазвичай це просто вибирається кліком на дані тригера: data або body).
11. Оберіть вашу папку ESP32-CAM.
12. У верхньому правому кутку натисніть кнопку Deploy (або переведіть тумблер в стан Active), щоб шлюз почав працювати постійно.

Крок 2: Налаштування камери

Код у src/main.cpp змінювати не потрібно, тому що він уже написаний універсально і відправляє чисті бінарні байти знімку.
1. Відкрийте сторінку конфігурації вашої камери в браузері (http://ip_камери:81).
2. У полі Google Script ID (назву поля ми залишили старою, щоб не переписувати інші файли) вставте повне посилання на ваш Webhook з n8n, яке ви скопіювали у Кроці 1 (воно має починатися з https:// і містити слово webhook).
3. Переконайтеся, що зелений тумблер активації відправки фото увімкнено, і натисніть Save.
Плата перезавантажиться і підключиться до домашнього Wi-Fi.
